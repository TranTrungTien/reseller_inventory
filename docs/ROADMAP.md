# Roadmap

## Milestone 1: Physical truth
Create bins, QR labels, add/capture items, offline search, move, mark sold.

## Milestone 2: Trust
Persistent DB wiring, outbox sync engine, cloud backup, CSV importer/exporter, undo, duplicate SKU guard, error/offline states.

## Milestone 3: Scale
Pick mode, bin audit, bulk move, label printing, multi-device/team activity.

## Milestone 4: Acquisition integrations
Marketplace-neutral import adapters, then eBay first. Keep CSV fallback. AI image metadata remains asynchronous and human-reviewable.

## Product metrics
Time-to-first-bin, time-to-first-item, capture time/item, search-to-found time, cannot-find rate, weekly store/find/move/pick actions, D7/D30 retention, item count per active workspace.
